Register the Coach GitHub App

Registers a read-only GitHub App with the permissions Coach needs for remote baseline scans. Serve this directory on port 8765 so the redirect URL matches the manifest. 

cd deploy/compose/platform
python3 -m http.server 8765
# then open http://127.0.0.1:8765/create-github-app.html
