Register the Coach Local Pilot GitHub App

This page posts the repo’s github-app.manifest.json to GitHub so you get the right read-only permissions without hand-clicking the App form. Serve it from this directory on port 8765 so the manifest redirect_url matches. 

cd deploy/compose/platform
python3 -m http.server 8765
# then open http://127.0.0.1:8765/create-github-app.html
